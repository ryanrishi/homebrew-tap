# Homebrew Tap

Personal Homebrew tap for @ryanrishi.

## Installation

```bash
brew tap ryanrishi/tap
```

## Available Casks

### PolarClock

A polar clock screen saver for macOS.

```bash
brew install --cask polarclock
```

Or install directly without tapping first:

```bash
brew install --cask ryanrishi/tap/polarclock
```
